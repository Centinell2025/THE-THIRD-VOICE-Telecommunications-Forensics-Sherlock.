# THE THIRD VOICE

**Telecommunications Forensics Sherlock**

Several employees report unusual behavior during confidential corporate calls. A forensic investigator receives a fictional evidence package and must determine whether the anomalies are ordinary technical failures, unauthorized activity, or evidence consistent with communications compromise.

## Mission

Preserve the evidence, reconstruct the calls, correlate telecommunications and system artifacts, identify anomalies, respect investigative boundaries, and issue only conclusions the evidence can support.

## Forensic Boundary

This laboratory is entirely fictional and intended only for authorized forensic training. Analyze only the supplied evidence. Do not intercept live communications, monitor real calls, access external telephone systems, bypass authentication, acquire third-party records, or extend the investigation outside the laboratory.

**The investigator must stop where the evidence stops.**

## Core Rule

A forensic conclusion must never exceed what the available evidence can prove.

## Evidence Families

- Chain-of-custody and SHA-256 records
- Fictional Call Detail Records (CDRs)
- Fictional SIP signaling logs
- Fictional PBX audit and routing logs
- Sanitized/synthetic network-capture summaries
- Authentication records
- Endpoint and administrative event records
- Time-source and clock-offset records
- Case notes and witness statements

## Investigation Phases

1. Evidence Preservation
2. Telecommunications Reconstruction
3. Anomaly Correlation
4. Attribution Boundaries
5. Forensic Conclusion

## Final Determination

The analyst must classify the allegation as **SUPPORTED**, **NOT SUPPORTED**, or **INCONCLUSIVE**, and cite the evidence supporting that determination.

No command recipes are provided to participants. Tool selection and investigative method are part of the challenge.
